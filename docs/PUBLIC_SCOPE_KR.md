# 공개 범위

이 공개 저장소는 안전한 로컬 테스트 파이프라인만 포함합니다.

허용 항목:

- `sample_data/` 아래 샘플 OHLCV CSV 데이터
- 교육용 이동평균 샘플 전략 1개
- 로컬 백테스트 파이프라인
- 로컬 paper-live 리플레이 파이프라인
- 범용 metrics/scoring 및 샘플 파라미터 최적화
- 선택적 Rust 샘플 백테스트 커널
- CI 검사, 테스트, 공개 사용 문서

금지 항목:

- 실제/독점 전략
- 연구 노트, 연구 리포트, 실험 산출물, 최적화 파라미터
- 프로덕션 데이터, 비공개 데이터셋, 데이터 수집 코드
- 거래소 커넥터 또는 실제 주문 라우팅
- 자격 증명, 환경 파일, 배포 설정, private remote 정보

향후 변경에서 공개 범위를 벗어나는 파일을 추가하면
`tests/public_safety_audit.py`를 갱신하고 CI를 통과시켜야 합니다.
